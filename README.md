# MATAS Kids — achievements

Редаговані визначення та структура дерева досягнень MATAS Kids. Платформа зберігає окремо факти отримання дітьми; персональних даних у цьому репозиторії немає.

## Як змінити дерево

1. Відредагуйте `achievements.json` у GitHub й збережіть commit.
2. У платформі відкрийте Директор → GitHub-контент → Досягнення → Прочитати GitHub.
3. Перевірте попередній перегляд і натисніть «Застосувати дерево». Без цього чинна версія в платформі не змінюється.

Чинне дерево:58 досягнень,7 розділів,65 оригінальних значків. Перенесено з погодженої локальної студії17.10.2026. Кожна нагорода описова; автоматичних грошових нагород або нових прав обладнання немає. Minecraft використовується лише як оформлення локальної платформи; його текстури/шрифт/визначення тут не публікуються. Директор може повернути вигляд Minecraft-демо, не стираючи отримані нагороди.

## Поля

`schemaVersion`:1. `trees`: розділи з `id`, `name`, `icon`. `nodes`: `id`, `treeId`, `parentId`, `name`, `condition`, `reward`, `skills`, `icon`, `x`, `y`, `frame`. `parentId:null` — корінь; інакше ID батьківського вузла того самого розділу. Цикли й невідомі батьки відхиляються. `x` — горизонтальна колонка, `y` — вертикальна позиція. Дробові позиції дозволені; однакові координати в розділі заборонені. `frame`:task/goal/challenge — вид рамки. Іконка — відносний шлях PNG/JPEG/WebP/SVG у цьому репозиторії. SVG використовуються як зображення.

**ID стабільні**, наприклад `matas:electronics/first-circuit`. Змінюйте назву й опис, а не ID, якщо це те саме досягнення. Зміна суті умови потребує нового ID. Видалений вузол архівується в платформі, отримані нагороди зберігаються. Оновлення замінює локальні описи імпортованих вузлів, тому довгострокові правки робіть тут. Батьківські зв’язки зараз визначають малюнок дерева; вони не запроваджують автоматичні правила допуску/видачі.

Локальна перевірка: `node scripts/validate.mjs`. Платформа додатково перевіряє JSON перед застосуванням і фіксує commit. Зображення теж читаються з цього commit. Не додавайте сюди імена дітей, нагороди конкретних учнів, контакти, баланси або ключі доступу.

## Розширення каталогу17.10.2026

`prerequisites` — усі попередники того самого розділу; `parentId` лишається сумісним основним батьком. `crossSectionPrerequisites` — окремі посилання на інші розділи, які показуються в картці; лінії між вкладками не малюються. Всі посилання перевіряються на існування та цикли. `description` — текст «Про досягнення». `background` розділу — один із stone/end/adventure/husbandry/nether/copper/blueprint; зовнішні фони не дозволені.

Рамки:task — Навичка;goal — Досягнення;challenge — Проєкт. Вихідні ID стабільно перенесені з префіксом matas:. Видалені попередні демовизначення архівуються платформою зі збереженням отриманих нагород. Не змінюйте ID після видачі дітям. Приватні local URLs, повні вихідні нотатки й дані дітей сюди не потрапляють.
